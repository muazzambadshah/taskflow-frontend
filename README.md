# TaskFlow Frontend

React 18 + Vite frontend for the TaskFlow task manager with protected routes, JWT auth and task filters. Backend: [taskflow-api](https://github.com/muazzambadshah/taskflow-api).

## Features
- Login / register with protected routes
- Add, edit, delete and filter tasks
- Stats cards dashboard
- Context + useReducer state, CSS Modules

## Tech Stack
React 18, Vite, React Router v6, Axios, CSS Modules

## Getting Started
```bash
git clone https://github.com/muazzambadshah/taskflow-frontend.git
cd taskflow-frontend
npm install
npm run dev
```
